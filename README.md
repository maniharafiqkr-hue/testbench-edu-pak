# TestBench

TestBench is an English-first self-assessment product for Pakistani board students. It turns practice into a measurable learning loop:

**Attempt → Mark → Understand → Rewrite → Retest**

## Current product slice

The first implementation targets FBISE Grade 10 English and includes:

- a public product landing page;
- a student home dashboard;
- diagnostic instructions;
- an interactive five-part English diagnostic prototype;
- an objective-result view with writing clearly marked as pending;
- a seven-day repair plan;
- an initial teacher marking queue.

The current screens use realistic demonstration data while product workflows and academic rubrics are validated with students and the pilot English teacher.

## Local development

The project uses the Vinext Sites starter with React and TypeScript.

```bash
npm install
npm run dev
```

The longer-term page architecture is being developed in phases. Public teacher marketplaces, social features, live classes, and CAIE past-paper republication are intentionally outside the first release.
